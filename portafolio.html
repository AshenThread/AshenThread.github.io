Guia para agregar proyectos nuevos

Usa esta estructura para escalar el portafolio con proyectos recientes de forma ordenada y consistente.

1. Prepara tus archivos

  • Imagen principal: 1600x900 (o 1920x1080), formato JPG/PNG.
  • Video opcional: link de YouTube/Vimeo.
  • Nombra por proyecto: proyecto-nombre-01.png.

2. Completa la ficha del proyecto

  • Nombre del proyecto.
  • Tipo: Unity, Motion Graphics, UI/UX, Web, Game Design, Branding.
  • Rol: que hiciste tu directamente.
  • Herramientas: Unity, C#, After Effects, Illustrator, Premiere, HTML/CSS/JS.
  • No usar Blender en la descripcion de herramientas.

3. Escribe una descripcion util

  • Objetivo: que problema resolviste.
  • Proceso: 1-2 decisiones de diseno importantes.
  • Resultado: que mejoro o que se logro.

4. Copia este template HTML

<div class="portfolio-item" data-category="unity ux">
  <div class="portfolio-image">
    <img src="Imagenes/Unity_IMG/tu-proyecto.png" alt="Nombre del proyecto">
    <div class="portfolio-overlay">
      <h3>Nombre del proyecto</h3>
      <p>Descripcion corta del objetivo y resultado.</p>
      <div class="portfolio-tags">
        <span class="tag">Unity</span>
        <span class="tag">UI en Unity</span>
      </div>
    </div>
  </div>
</div>

Este formulario genera el HTML localmente y puede insertar la tarjeta en la vista o copiar el fragmento para revisión. No publica nada automáticamente en GitHub.
