# AshenThread Portfolio

Portfolio personal para GitHub Pages.

## Deploy en GitHub

1. Sube este repositorio a GitHub.
2. Ve a Settings > Pages.
3. En Source selecciona "Deploy from a branch".
4. Elige la rama principal y la carpeta "/root".
5. Guarda y espera a que se publique la web.

## Archivos importantes

- `index.html`: página principal para GitHub Pages
- `portafolio.html`: versión original del sitio
- `Styles.css`: estilos
- `main.js`: interactividad y filtros
